# Горящие туры — Telegram-бот

Как работает:
1. Раз в день задача по расписанию в приложении Claude открывает в Chrome Аслана
   `https://pro.tourvisor.ru/search?tab=hotOffers` (кабинет агентства, вылет из Астаны)
   и запускает в странице `collect.js`. Скрипт собирает туры и ссылки «Поделиться» (tourcart.ru).
2. Результат отправляется боту: `POST https://<адрес-бота>/update`, заголовок `X-Secret` из файла `.update-secret`.
3. Бот (`worker.js`, Cloudflare Workers) сохраняет туры, публикует в канал до 3 новых туров с самой большой скидкой
   и отвечает клиентам: /start → кнопки со странами → 5 самых дешёвых туров.

Пароль от Tourvisor нигде не хранится: туры берутся из уже открытого браузера.

Проверка без Telegram: `node check.mjs` (должно вывести OK).
